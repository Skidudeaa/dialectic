## Behavior

- **Evidence beside the thought.** `ToolLoop._execute` stamps `evidence` on a trace entry whenever a source tool returned something: `read_article`/`read_reddit` (one item: url, title, author, site, published, `content_sha256`, the first 400 characters the model saw, `content_start` for a continuation window), `search_reddit` (up to 6 hits) and `search_reading` (up to 6 library rows with `reading_id`). `llm.tools.evidence_of` is the one reader of those four result shapes; quotes, proposals and memory stamp nothing. It rides `metadata.tools.calls[]` on every path that persists a trace (addressed turns, forced turns, research), so it needs no migration and no new message slot.
- **The card.** A machine message carrying evidence renders `Evidence · N sources` under its prose: title or host, `Open original ↗` (new tab, `noopener noreferrer`), byline, the excerpt as a quotation, `revision <8 hex>`, `Save to room`, and a `Raw tool payload · <tool>` disclosure holding the call input and the stamped item. A library row shows `in the library` instead of Save. When a library item's `content_sha256` differs from the hash on a quoted `reading_items` ref of the same id (the message's own refs or the thread's source), the card says `Source revision differs from the quoted passage (<8 hex>)` rather than standing in for it. Streaming and human messages never render the card.
- **Save to room** posts the existing `POST /rooms/{id}/reading/file` with the answer's own message id and the fetched url. The route's provenance rule widened by exactly that: a url counts as appearing in the message when it is in the prose **or** in the message's stamped evidence. A url the answer never fetched is still refused (422). First-attempt failure shows `Retry save`; success shows `saved to room`.
- **Overview clusters.** At 50% zoom and below, with no focused path, every reply subtree of four or more thoughts folds into one dashed cluster card: `N replies to <author>` and `<people> · S sources`, hanging from its parent by the real reply edge. `Expand` reopens one branch; a still-large sub-branch folds in turn, so the expansion path is explicit and one level at a time. `Focus path` on a cluster focuses its parent. Zooming past 50% unfolds without a click; `Show whole map` forgets expansions. The toolbar counts `· N folded branches`. Passages cited only inside a folded branch leave with it. No agreement or opposition is inferred.
- **The participant as a branch tool.** Beside `Find and pull`, every thought now offers `Challenge`, which stages an editable request under that exact thought: "@Dialectic challenge this thought. Give the strongest specific counter-evidence or the weakest step in the reasoning, with a source where you can find one. Two or three sentences." Existing draft text stays; only Send runs anything. Production already runs `DIALECTIC_ADDRESSED_ONLY=1` and `ANNOTATOR_ENABLED=0`, so in reading rooms the participant speaks only when summoned; its answer lands in the branch that asked, with the evidence card under it.

No migration. No dependency or production config change. This tranche adds no production contributions and triggers no model generations.
